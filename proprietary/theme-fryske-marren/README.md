# Fryske Marren Theme

Design tokens for the De Fryske Marren municipality theme.

## Installation

```bash
pnpm add @openwebconcept/theme-fryske-marren
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-fryske-marren/dist/theme.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-fryske-marren/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-fryske-marren';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
