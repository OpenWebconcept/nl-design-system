# Gooise Meren Theme

Design tokens for the Gooise Meren municipality theme.

## Status: empty theme

This theme has no tokens of its own yet. It shows the defaults from `@openwebconcept/design-tokens`, scoped to the `.theme-gooise-meren` selector, until the Gooise Meren design tokens are added.

## Installation

```bash
pnpm add @openwebconcept/theme-gooise-meren
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-gooise-meren/dist/index.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-gooise-meren/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-gooise-meren';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
