# Leiden Theme

Design tokens for the Leiden municipality theme.

## Status: empty theme

This theme has no tokens of its own yet. It shows the defaults from `@openwebconcept/design-tokens`, scoped to the `.theme-leiden` selector, until the Leiden design tokens are added.

## Installation

```bash
pnpm add @openwebconcept/theme-leiden
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-leiden/dist/index.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-leiden/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-leiden';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
