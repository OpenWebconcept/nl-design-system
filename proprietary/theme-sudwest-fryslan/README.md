# Súdwest-Fryslân Theme

Design tokens for the Súdwest-Fryslân municipality theme.

## Status: empty theme

This theme has no tokens of its own yet. It shows the defaults from `@openwebconcept/design-tokens`, scoped to the `.theme-sudwest-fryslan` selector, until the Súdwest-Fryslân design tokens are added.

## Installation

```bash
pnpm add @openwebconcept/theme-sudwest-fryslan
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-sudwest-fryslan/dist/index.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-sudwest-fryslan/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-sudwest-fryslan';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
