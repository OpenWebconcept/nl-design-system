# Ridderkerk Theme

Design tokens for the Ridderkerk municipality theme.

## Status: empty theme

This theme has no tokens of its own yet. It shows the defaults from `@openwebconcept/design-tokens`, scoped to the `.theme-ridderkerk` selector, until the Ridderkerk design tokens are added.

## Installation

```bash
pnpm add @openwebconcept/theme-ridderkerk
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-ridderkerk/dist/index.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-ridderkerk/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-ridderkerk';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
