# Roosendaal Theme

Design tokens for the Roosendaal municipality theme.

## Status: empty theme

This theme has no tokens of its own yet. It shows the defaults from `@openwebconcept/design-tokens`, scoped to the `.theme-roosendaal` selector, until the Roosendaal design tokens are added.

## Installation

```bash
pnpm add @openwebconcept/theme-roosendaal
```

## Usage

### CSS

```css
@import '@openwebconcept/theme-roosendaal/dist/index.css';
```

### SCSS

```scss
@import '@openwebconcept/theme-roosendaal/dist/variables';
```

### JavaScript

```js
import tokens from '@openwebconcept/theme-roosendaal';
```

## Building

```bash
pnpm run build
```

## Development

```bash
pnpm run watch
```
